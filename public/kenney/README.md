# Kenney 3D kits (CC0)

Free models by Kenney (www.kenney.nl), CC0 licence (see each `License.txt`). Use them as props in any short.

- `nature-kit/` (Nature Kit 2.1): 329 models: trees, bushes, flowers, rocks, grass, cliffs, paths, tents, canoes...
- `fantasy-town-kit/` (Fantasy Town Kit): 167 models: walls, roofs, stalls, carts, lanterns, banners, fountains,
  windmill... These need `Textures/colormap.png` beside them: copy that folder too when moving models.

Load one in Remotion with `staticFile("kenney/nature-kit/tree_oak.glb")` and three's GLTFLoader (see
`src/videos/bridge/world.ts`). Re-download from kenney.nl/assets/nature-kit and kenney.nl/assets/fantasy-town-kit.
