# Kenney props (download once per machine)

The bridge town loads these free CC0 models from this folder. They are not in git.

1. Download **Nature Kit** (https://kenney.nl/assets/nature-kit) and **Fantasy Town Kit** (https://kenney.nl/assets/fantasy-town-kit).
2. From each zip, copy the `.glb` files (in `Models/GLB format/`) into this folder.

Files the bridge uses: tree_oak, tree_default, tree_detailed, tree_fat, tree_cone, tree-high-round, tree,
plant_bushLarge, plant_bushDetailed, plant_bush, hedge, flower_redA, flower_yellowA, flower_purpleA, grass_large,
grass, lily_large, lantern, cart, stall-red, stall-green, stall-bench, banner-red, banner-green, windmill, canoe.

Without them the short still renders, just without trees, stalls and other props.
